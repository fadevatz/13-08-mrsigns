# Mr. Signs — Landing Page & Uniformes Personalizados nos EUA 🇺🇸

Landing Page oficial da **Mr. Signs** — Gráfica Brasileira e Confecção de Uniformes nos Estados Unidos.

## 🚀 Tecnologias Utilizadas
- **HTML5 & CSS3 Vanilla** (Sem frameworks desnecessários, carregamento ultra-rápido)
- **JavaScript ES6+** (Simulador de orçamento para WhatsApp, filtros de galeria e lightbox)
- **Google Fonts** (Bebas Neue + Plus Jakarta Sans)
- **FontAwesome Icons**
- **Docker & Nginx Alpine** (Pronto para deploy de alta disponibilidade)

---

## 📦 Como Rodar com Docker

### 1. Build da Imagem Docker
```bash
docker build -t mrsigns-web .
```

### 2. Executar o Container
```bash
docker run -d -p 8080:80 --name mrsigns-container mrsigns-web
```
Acesse no seu navegador: `http://localhost:8080`
